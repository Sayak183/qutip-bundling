R4 EXTENDED TO DIM 64 -- STEP 3 OF 4 (run_isocost_vs_dim.py)
=============================================================
ONE file. NOTE R4 IS STRUCTURALLY DIFFERENT from R1/R3: its x-axis IS
dimension, so every size lives in ONE file and ONE figure -- there is no
PLOT_DIM switch here and none is wanted. "Sweep everything" for R4 means
extending the size list and REMOVING THE WALL that stopped it.

WHAT CHANGED
 1. Sizes extended: spin dims 4..64 (was 4..32); oscillator dims 8..64
    (was 8..32), the dim-64 point at 16 disclosed substeps.
 2. THE WALL IS GONE. Previously the loop hit `break` the moment mesolve
    became infeasible -- that is exactly why your R4 spin curve stopped at
    dim 32. It now falls back to the certified native full-dissipator
    reference (substep-halving self-check; an uncertifiable size is SKIPPED,
    not trusted), so the curve continues past the mesolve wall.
 3. Per-size substeps threaded through the SLB sweep and recorded in the data
    (substeps_by_size in meta), so the disclosed oscillator dim-64 point is
    self-documenting.
 4. SOFT-DIVERGENCE GUARD in the sweep (finite-but-garbage samples end that
    dimension's sweep instead of poisoning it).
 5. MCSOLVE WALL-CLOCK CAP: a per-dimension budget (MC_TIME_BUDGET_S = 1 h)
    stops the ntraj ladder before it can run for hours. Skipped ntraj values
    are RECORDED (mc_skipped); S^2 is a property of the system, so using fewer
    sampled ntraj costs precision, not validity.
