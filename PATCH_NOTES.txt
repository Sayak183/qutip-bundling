CONVERGENCE + JACKKNIFE, HIGH-SAMPLING (benchmark_convergence.py) -- v3
========================================================================
Purpose: push the oscillator's SEM noise floor DOWN so the jackknife's steep
bias rate is resolved over more M values (you saw it clear the floor by M=8 at
256 realizations, leaving only 2 clean points and a noisy zig-zag past that).

CHANGES:
 - Per-system realization counts: spin_chain stays 256 (already clean); the
   oscillator jumps to 4000 (its bias is ~10x smaller, so it needs ~16x more
   samples to expose the same clean range). Each system's SEM floor now uses
   ITS OWN count.
 - INCREMENTAL SAVE: after every M it writes convergence_progress_<system>.json,
   so a multi-hour run is never lost to a crash or a morning Ctrl-C.
 - CLI: --scale N multiplies both counts (e.g. --scale 2 -> spin 512, osc 8000)
   if 4000 still isn't enough; --only oscillator_bath runs just one system.
 - Fixed the title/annotation overlap you spotted.

EXPECTED COST: the oscillator at 4000 realizations x 6 M-values x jackknife is
HEAVY -- likely 1.5-3 hours. That's what the night is for. The spin chain at
256 finishes in a few minutes first, so you'll see it complete early, then the
oscillator grinds.
