THE PATTERN:
 - run_accuracy_vs_M.py now sweeps a LIST of sizes per system (dims 16/32/64;
   the oscillator's dim-64 uses 16 substeps, disclosed). It computes each size
   ONCE and saves one file per dim: accuracy_vs_M_<system>_dim<D>.json.
   Nothing overwrites; your existing dim-16 file stays.
 - Past the mesolve memory wall it falls back to the certified native RK4
   reference (same as Result 2), with a self-check that SKIPS any size whose
   reference can't be certified. Soft-divergence in the SLB sweep is guarded
   and that M is skipped.
 - plot_accuracy_vs_M.py has a new switch: PLOT_DIM. Set it to 16 / 32 / 64 to
   draw that size (fast); None auto-picks the largest dim on disk.

WORKFLOW (what you asked for -- heavy run once, fast plotting after):

  python run_accuracy_vs_M.py

  # FAST, anytime: pick a size and plot
