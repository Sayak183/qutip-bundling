# Legacy benchmark data

These files are retained for historical provenance and are not inputs to the
published figures.

- Unsuffixed `accuracy_vs_M_*.json` and `frontier_*.json` are older
  dimension-16 runs from before the current per-dimension filenames and solver
  provenance fields were introduced.
- `cost_scaling_oscillator_bath.PARTIAL.json` is an interrupted run superseded
  by `../cost_scaling_oscillator_bath.json`.
- `csv/` contains the matching older, unsuffixed CSV exports.

Use the canonical files listed in [`../README.md`](../README.md) for analysis.
